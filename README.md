## 🧭 How I work

- **Start with the user's workflow.** Consider validation, feedback, and failure states alongside the happy path.
- **Write maintainable code.** Use clear names and focused methods; keep complexity justified and document decisions that need context.
- **Test behavior that matters.** Protect business rules and important user journeys with RSpec and Capybara.
- **Think through production.** Account for time zones, background jobs, external-service failures, and deployment.
- **Communicate clearly.** Make assumptions explicit, raise questions early, and leave useful context for teammates.
